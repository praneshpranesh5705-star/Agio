# AGIO — Smart Agriculture

Agio is a cinematic, responsive smart-farming website combining the scroll-driven interaction pattern of the Itzfizz assignment with an original agriculture experience.

## Included
- Scroll-driven pinned hero with a moving tractor and precision-farming headline reveal.
- AI crop vision, smart irrigation, IoT and drone/GPS feature sections.
- Live-style soil, temperature, humidity and crop-health cards.
- Interactive-looking farm monitoring dashboard.
- Responsive mobile navigation and layouts.
- Reduced-motion support.
- Static export and GitHub Pages deployment workflow.

## Stack
Next.js 14 · React 18 · GSAP + ScrollTrigger · CSS · GitHub Actions

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to `main`, then enable **Settings → Pages → GitHub Actions**. The workflow builds the static `out` folder and deploys it automatically.

## Design direction
The project uses the scroll choreography concept from the referenced Itzfizz assignment, but the Agio visual identity, agricultural copy, UI, dashboard, tractor illustration and feature system are original to this project.
